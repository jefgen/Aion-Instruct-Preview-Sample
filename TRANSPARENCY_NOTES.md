## Transparency Notes

This repository contains an experimental release of a Microsoft-developed Small Language Model (SLM) – Aion 1.0 Instruct, intended for prototyping only.

This release is not the final released model and may:

- Contain incomplete or unoptimized functionality,
- Produce inaccurate, inconsistent, or unexpected outputs,
- Differ in quality, performance, capabilities, APIs, or behavior from future production versions.

The model and SDK are provided as-is without guarantees of accuracy, reliability, availability, or fitness for a particular purpose.

### Intended Use

Example supported experimentation scenarios include:

- Text generation,
- Rewriting,
- Summarization.

Outputs generated by the model should always be reviewed and validated by a human before use.

### Not Recommended For

This release must not be used for:

- Medical, legal, financial, or other high impact decision making,
- Safety critical systems or automated operational control,
- Generating harmful, violent, explicit, abusive, or illegal content,
- Deceptive or misleading activities, including misinformation, impersonation, fraud, or spam,
- Fully autonomous actions without appropriate human oversight,
- Production workloads requiring guaranteed accuracy, reliability, or deterministic behavior.

### Model Behavior and Limitations

As an experimental SLM, Aion Instruct may:

- Hallucinate or generate factually incorrect information,
- Reflect biases or limitations present in training data
- Fail to follow instructions consistently
- Generate incomplete, malformed, or low-quality outputs

Performance, latency, memory usage, and output quality may vary depending on device hardware and configurations.

### Distribution and Runtime Notes

This release may include hardware specific compiled or cached model artifacts generated locally on device during runtime initialization. These artifacts are intended solely for local execution and evaluation as part of the model's runtime environment.

### Feedback

We welcome developer feedback and experimentation results to help improve future versions of the model and the Windows AI platform.
