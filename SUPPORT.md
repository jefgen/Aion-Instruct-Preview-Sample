# Support

## How to file issues and get help

This project uses **GitHub Issues** to track bugs and feature requests. Before
filing a new issue, please search the
[existing issues](https://github.com/microsoft/Aion-Instruct-Preview-Sample/issues)
to avoid duplicates. To report a bug or request a feature,
[open a new issue](https://github.com/microsoft/Aion-Instruct-Preview-Sample/issues/new/choose)
and pick the appropriate template.

For setup or runtime problems, run the diagnostic first and attach its output to
your issue:

```powershell
.\scripts\Diagnose-AionInstructPreview.ps1 | Tee-Object diag.txt
```

See the [README](README.md) for prerequisites, quickstart, and troubleshooting.

To report a security vulnerability, follow [SECURITY.md](SECURITY.md) — do **not**
open a public issue.

## Microsoft Support Policy

Aion Instruct Preview is a developer preview. Support is limited to the GitHub
Issues described above; there is no formal support SLA.
